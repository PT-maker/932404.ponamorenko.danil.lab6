| GET | `/about` | Страница «О себе» |
| GET | `/api/movies` | Список фильмов в формате JSON |
| GET | `/api/status` | Статус сервера (JSON) |
| GET | `/docs` | Документация API (генерируется FastAPI) |

### GET /api/movies

Возвращает массив объектов `{ "title", "year", "rating" }`, отсортированный по рейтингу по убыванию.

Query-параметр `minRating` (число от 0 до 10) оставляет только фильмы с рейтингом не ниже указанного.

```
GET /api/movies                 → все фильмы
GET /api/movies?minRating=8.8   → фильмы с рейтингом от 8.8
GET /api/movies?minRating=abc   → 400 Bad Request
```

Пример ответа:

```json
[
  { "title": "Побег из Шоушенка", "year": 1994, "rating": 9.3 },
  { "title": "Крёстный отец", "year": 1972, "rating": 9.2 }
]
```

Ошибки: при невалидном `minRating` (не число, пустое значение, значение вне диапазона 0–10, повтор параметра) сервер отвечает статусом `400` и телом:

```json
{ "error": "minRating должен быть числом от 0 до 10" }
```

## PWA

- `public/manifest.json` содержит название, цвета, режим `standalone` и иконки, подключён в `<head>` страниц.
- `public/sw.js` при установке кеширует страницы, стили, скрипты, манифест, иконки и список фильмов. Запросы идут сначала в сеть, при её отсутствии ответ берётся из кеша, поэтому приложение работает офлайн.
- Service worker регистрируется в `public/app.js` и в `about.html`.

### Как проверить офлайн-режим

1. Откройте http://localhost:3000 и один раз загрузите страницу.
2. В DevTools (F12) → Application → Service Workers убедитесь, что service worker активен.
3. Остановите сервер (`Ctrl+C`) или включите режим Offline и обновите страницу. Страница и список фильмов должны открыться из кеша.
